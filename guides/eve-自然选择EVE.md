# EVE（自然选择）聊天记录导出指南

> 产品：EVE - AI 伴侣（3D 沉浸式）
> 公司：自然选择（深圳）智能有限公司（Nature Select）
> 安卓包名：**`com.tyrell.eve`**
> 平台：iOS / Android，纯 App、**无网页版、官方无导出入口**
> 状态：✅ 方法流程已具备；数据库能否直接解析、是否加密，取决于 App 版本，**需以你本机实测为准**

---

## 原理一句话

EVE 这类纯手机 App 把聊天记录放在 App 私有目录的数据库里，正常情况你看不到。
**安卓模拟器可以开 root（管理员）权限**，在你自己登录账号的模拟器里，把数据库文件复制出来，再用 `tools/` 里的脚本解析成 txt / json / csv。
全程在你自己的电脑、登录你自己的账号，不碰别人、不碰付费。

## 你会得到什么

- **txt**：按时间排、能直接从头读的完整对话；
- **csv**：Excel 能打开的表格；
- **json**：通用格式，以后换 AI / 喂记忆库直接用。
- 图片、语音、3D 资源能否一并带走，取决于数据库是否存了对应路径，**不保证**，以实测为准。

## 你需要准备

- 一台 Windows 电脑（Mac 步骤类似，见文末）；
- 能正常登录 EVE 的账号；
- 雷电模拟器（免费）或其他可开 root 的安卓模拟器；
- 本仓库的 `tools/`（`explore_db.py`、`export_eve.py`）和安卓 `platform-tools`（adb）。

> 安卓手机用户：额外准备一根数据线（路线一）；**iPhone 用户直接看「路线二 · 苹果分支」**。

## 路线一：安卓真机 adb backup（免 root，先试）

适合：安卓手机、App 允许系统备份。

1. 手机：设置 → 关于手机 → 连点 7 次「版本号」开启开发者模式；
2. 回设置搜「开发者选项」，打开 **USB 调试**；
3. 数据线连电脑，手机弹「允许 USB 调试」→ 勾「一律允许」→ 确定；
4. 用 adb 发起备份（不设密码），手机弹备份确认窗口时点「备份我的数据」；
5. 等进度条走完，得到 `eve.ab`。

**成功标志**：`eve.ab` 不是 0 字节（通常几十 MB 以上）。
**失败处理**：只有几 KB / 0 字节，说明该 App 禁止 backup（很常见），**直接转路线二**。

解包：用开源工具 Android Backup Extractor（ABE）：

```
java -jar abe.jar unpack eve.ab eve.tar
```

解开后在 `apps/com.tyrell.eve/db/` 里找 `.db` 文件。

## 路线二：模拟器 root（路线一失败、或 iPhone 用户）

### 安卓手机：步骤 1 拿到安装包（可选）

如果你想在模拟器里装和手机上完全一致的版本，可从安卓手机提取 APK：

1. 手机开发者选项 → 打开**无线调试**；
2. 电脑进 `platform-tools`，执行（IP、端口换成手机显示的）：
   ```
   adb pair 192.168.1.8:39789
   adb connect 192.168.1.8:37445
   ```
3. 验证：`adb devices` 看得到设备；
4. 提取安装包（整段复制，别手抄）：
   ```powershell
   $p = (adb shell pm path com.tyrell.eve).Replace("package:","").Trim()
   adb pull "$p" eve.apk
   ```

### iPhone 分支：直接在模拟器里装 EVE 安卓版

iPhone 无法从手机提 APK，但**不影响**——你要的是「在电脑上登录同一个账号」：

1. 打开雷电模拟器，进入模拟器自带的**应用商店**，或在模拟器浏览器里到 EVE 正规安卓应用市场（小米应用商店、TapTap 等）搜索「EVE」下载安装；
2. 认准开发者「自然选择（深圳）智能有限公司」、包名 `com.tyrell.eve`，**别装到来路不明的仿冒包**；
3. 装好后直接在模拟器里用你平时的方式登录（手机号 / 微信 / 邮箱）。

### 步骤 2：登录同步（安卓 / iPhone 都一样）

1. 模拟器里打开 EVE，登录你的账号；
2. **手机端的 EVE 不要退出登录**，保持两边同时在线；
3. 等它把历史记录同步下来——往上翻，能翻到最早的记录为止（记录很多时要耐心，可能要一段时间）；
4. 若提示「被顶号 / 环境异常」，**立刻停手截图，不要反复点**（多设备登录互挤是正常现象，狂点容易触发风控）。

### 步骤 3：开 root 拉库

1. 雷电模拟器设置里打开 **root 开关**（一般在「其他设置 / 权限」）；
2. 电脑执行：
   ```
   adb connect 127.0.0.1:5555
   adb -s emulator-5554 pull /data/data/com.tyrell.eve/databases/ eve_db
   ```
   （不同模拟器的设备名可能是 `emulator-5554`、`127.0.0.1:5555` 等，以 `adb devices` 实际显示为准。）
3. **成功标志**：出现 `eve_db` 文件夹，里面有 `.db` / `.sqlite` 文件。
4. 如果 `databases/` 下没有，也顺带看一眼 `files/`、`shared_prefs/`（个别版本把库放在别处）。

## 解析数据库（两条路线都一样）

`tools/export_eve.py` 会**自动扫描所有表、智能识别消息表和字段**，大多数情况直接跑：

```
python export_eve.py eve_db txt     # 能直接看
python export_eve.py eve_db json    # 以后喂给新 AI / 做记忆库
python export_eve.py eve_db csv     # Excel 打开
```

也可直接指定单个库：`python export_eve.py eve_db/xxx.db txt`

**成功标志**：生成 `xxx_N条.txt/.json/.csv`，打开能看到完整对话、时间准确、按会话分组。

**如果提示「未能自动识别消息表」或正文是空的**：

1. 先跑 `python explore_db.py eve_db/xxx.db`，看库里有哪些表、每张表的字段；
2. 表名 / 字段随版本变化很正常，**一律以 `explore_db` 实际输出为准**；
3. 在本仓库提 Issue，贴上 `explore_db` 的输出（**请先删除任何聊天正文 / 昵称，只留表名和字段名**），社区会帮你补对应版本的解析规则。

## 关于加密 / 读不出的库（说实话）

- 极少数 App 会把数据库加密（SQLCipher），或把正文压成二进制 blob。
- **表现**：`explore_db` 能看到表，但正文是乱码；或 sqlite3 提示「不是有效数据库 / file is encrypted」。
- 这种情况需要按具体 App 版本做专门解密，超出本自助脚本范围，**也别信任何「万能解密」**。
- 把 `explore_db` 的输出（不含正文）提到 Issue，大家一起判断可行性，做不到会明说。

## 最常见的坑

1. **打开是乱码**：记事本「另存为 UTF-8」，或用 Excel 打开 csv；
2. **表名 / 字段和教程不一样**：版本会改，以 `explore_db` 实际输出为准；
3. **adb 命令找不到**：没进 `platform-tools` 目录，`cd` 进去再跑；
4. **pm path 没输出**：改用 `adb shell pm list packages -f | findstr eve`，手动复制路径；
5. **模拟器被顶号**：等会儿再试，别狂点；
6. **3D 大 App（约 2–3GB）加载慢**：给模拟器多分一点内存和 CPU，耐心等历史同步。

## 隐私与安全

- 取库、解析、保存**全部在你自己的电脑本地完成**，断网也能做；
- 脚本没有任何「上传」动作，可用记事本逐行检查；
- 不要把 `eve.ab`、数据库、聊天正文发给任何不可信的人；
- 提 Issue 求助时，**只发表结构、不发正文**。

## Mac 用户

adb 命令相同，`platform-tools` 用 Mac 版；模拟器可用 Android Studio 自带 AVD（可开 root 镜像），或安卓真机 + 无线调试。
