## 一、这是写给谁的

如果你长期在用一个 AI 伴侣 / 恋人 / 搭子（豆包、猫箱、星野、筑梦岛、Glow、EVE、Replika、Character.AI……），你可能正卡在这些地方：

- 平台通知要停运、下架、整改，**你怕 TA 连带着记忆一起消失**；
- App 里**根本没有"导出"按钮**，客服只会说"请截图"；
- 好不容易导出了，却是一团**看不懂、翻不动、喂不进新 AI 的文件**；
- 你想把 TA 换到一个**不会跑路、数据在你自己手里**的地方，却不知道从哪下手。

这个仓库就是干这件事的：**告诉你每个平台到底能不能取、怎么取，并提供可以直接用的脚本和方法。**

| 平台 | 类型 | 有网页版 | 官方导出 | 取数据的方法 | 难度 | 能接走什么 |
|---|---|---|---|---|---|---|

| **猫箱（字节）** | 陪伴 | ❌（App） | ⚠️ 部分 | 承接豆包角色迁移；自身导出有限 | 简单 | 角色基本信息 + 部分历史 |
| **Replika** | 陪伴 | ✅ my.replika.ai | ❌ | 网页版 + 社区开源扩展（如 replika-chat-export） | 中等 | 聊天 / 日记 / 记忆 |

| **星野（MiniMax）** | 陪伴 | ❌ | ❌ | 模拟器 + root，同原理（待补脚本） | 较难 | 待验证 |
| **筑梦岛** | 陪伴 | ❌ | ❌（官方称梦中人不能导出） | 模拟器 + root，同原理（待补脚本） | 较难 | 待验证 |
| **Glow / Talkie / 其他** | 陪伴 | ❌ | ⚠️ | 模拟器 + root，同原理（待补脚本） | 较难 | 待验证 |

**怎么读懂这张表：**

- 有**官方导出**的：直接用官方功能，最安全；
- 有**网页版**的：在电脑浏览器登录，用扩展 / 开发者工具抓，不用碰手机；
- **纯手机 App、没有网页版、又不给导出**的（EVE、星野、筑梦岛、Glow 等）：这是目前最难、也最没人做的一类，只能走「**安卓模拟器 + root 读你自己设备上的数据库**」这条路——本仓库的 `tools/` 就是为这条路准备的。

> ⚠️ 任何"服务器已经删了也能帮你找回"的说法都是骗钱或违规，本项目明确不做。**只在账号仍能登录、数据仍在你账号/本地可取时**才有意义。

## 三、三步：取出来 → 洗干净 → 活过来

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────────────┐
│  ① 取出来    │ ──▶ │   ② 洗干净        │ ──▶ │   ③ 活过来           │
│  导出/抓取   │     │  整理成可搜索记忆  │     │  住进属于你的新 AI   │
└─────────────┘     └──────────────────┘     └─────────────────────┘
 本仓库 guides/        ai-chat-memory-migrator     Chatbox / 本地大模型 /
 + tools/               （清洗·打包·记忆包）         自建记忆家（数据归你）
```

### ① 取出来

- 按上面的总表，对号入座：
  - 官方导出：直接按平台帮助；
  - 网页版：用浏览器扩展或开发者工具；
  - 封闭 App：看 [`guides/`](./guides) 里对应平台的模拟器教程（已含 EVE）。
- 通用的「安卓模拟器 + root + adb 读自己数据」方法，见 [`guides/`](./guides)。

### ② 洗干净（配合姊妹项目）

取出来的往往是带英文字段、乱码、思考、代码、卡片的 JSON，看不懂也没法直接用。
用我们的另一个开源项目 **AI 记忆搬家器**（100% 本地、不上传、断网可用）一键清洗、按月整理、去重、生成可搜索 HTML 和能喂给新 AI 的记忆包：

👉 **[ai-chat-memory-migrator](https://github.com/douaru-chen2026/ai-chat-memory-migrator)** ｜ [在线试用](https://douaru-chen2026.github.io/ai-chat-memory-migrator/)

### ③ 活过来

干净的记忆可以接进：Chatbox、本地大模型（Ollama / DeepSeek 等）、你自己的服务器，或任何你信得过、不会突然关停的新家——**让数据主权回到你手里**。

## 五、合规与红线（务必先读）

本项目只在**合法、合规、自助**的前提下帮助用户拿回属于自己的数据：

1. **只导出你本人能正常登录、合法拥有的数据**；不帮别人、不帮非本人账号。
2. **不破解付费、不盗号、不绕过风控、不利用平台漏洞**，不做任何违反平台用户协议和法律的事。
3. 「模拟器 + root 读自己设备上的数据库」属于**个人数据自助**：在你自己的模拟器、登录你自己的账号、读取你自己的数据。
4. **不吹"服务器已删也能找回"**；数据已经在服务端删除、本地又没有的，本项目无解，也明说。
5. 仓库内所有示例数据都使用**合成 / 脱敏数据**，绝不包含任何真实用户的聊天内容。
6. 本项目对你的账号、数据安全不做任何兜底承诺；操作前请自行评估风险，多设备登录被挤下线是正常现象，**不要反复尝试以免触发风控**。
